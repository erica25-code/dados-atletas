# 🏅 Dados dos Atletas

Este projeto foi desenvolvido em **JavaScript** como parte de um **Projeto de Certificação**.  
O objetivo é criar uma aplicação capaz de receber informações de um atleta, calcular parâmetros importantes e exibi-los no console.

---

## 📌 Funcionalidades

A aplicação permite:

- Armazenar dados do atleta (nome, idade, peso, altura e notas)
- Calcular a **categoria** do atleta com base na idade
- Calcular o **IMC (Índice de Massa Corporal)**
- Calcular a **média válida** das notas (descartando a maior e a menor)
- Exibir todas as informações no console

---

## 🧠 Regras Utilizadas

### 📂 Categoria do Atleta
- Infantil: 9 a 11 anos  
- Juvenil: 12 a 13 anos  
- Intermediário: 14 a 15 anos  
- Adulto: 16 a 30 anos  
- Sem categoria: demais idades  

### ⚖️ Cálculo do IMC

### 📊 Média Válida
- Remove a **maior nota**
- Remove a **menor nota**
- Calcula a média com as notas restantes
